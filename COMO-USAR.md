# Perfil GitHub — Samuel Alves

Proposta visual e editorial para o perfil samuasouza.

## Aplicar no GitHub

1. Abra https://github.com/samuasouza/samuasouza.
2. Adicione a pasta `assets` deste pacote na raiz do repositório, ao lado do README.md. No envio pelo navegador, preserve a pasta: os arquivos precisam ficar em `assets/header.svg`, `assets/typescript.svg` e assim por diante.
3. Substitua o conteúdo do README.md atual pelo README.md deste pacote.
4. Confira a aba Preview antes de salvar. Se o banner ou os badges não aparecerem, confira os caminhos e a presença da pasta `assets` na mesma branch.

O perfil aparece a partir do README.md da branch padrão. Nenhuma alteração foi publicada automaticamente.
